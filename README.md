# RADIO_creep
Radio creep v1.0

## What is Radio CREEP?

radioCREEP python app was the backbone of the iOS application of the same name: check it out! https://apps.apple.com/us/app/radiocreep/id6756237336.

## Features
-  Record any duration of minutues of audio!
-  Real‑time energy‑stability analysis
-  Spectral fingerprint visualisation
-  Save raw energy & FFT data for later inspection!
-  ...and more to come!
## How to Use!
1️⃣ Create (and activate) a virtual environment

python -m venv .venv
source .venv/bin/activate OR on Windows: .venv\Scripts\activate

2️⃣ Install everything

pip install -r requirements.txt

3️⃣ Run any of the apps

python sound_analyzer.py
python yeah_like.py     
python view_fingerprints.py --file data/sample_fingerprint.npy
